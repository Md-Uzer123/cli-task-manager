#  CLI Task Manager

A command-line Task Manager built with Python — Add, View, Update and Delete tasks with Input Validation and Error Handling.

##  Features
-  Add new tasks
-  View all tasks
-  Update existing tasks
-  Delete tasks
-  Input Validation & Error Handling

##  Tech Stack
- Python 3.x
- JSON (data storage)
- CLI (Command Line Interface)

##  How to Run

```bash
python task_manager.py
```

##  Menu Options

| Option | Action |
|--------|--------|
| 1 | Add Task |
| 2 | View Tasks |
| 3 | Update Task |
| 4 | Delete Task |
| 9 | Exit |
